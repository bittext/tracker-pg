# Security Program and Evidence

This repository includes operational security controls and documentation for **Health Tracker & PFM (Personal Financial Management)**.

## Security program statement

We maintain documented information security policies and procedures that are operationalized to identify, mitigate, and monitor information security risks relevant to our business.

The program includes:

- Governance and policy ownership
- Access control and authentication
- Secure configuration and hardening
- Logging, monitoring, and incident handling
- Change management and deployment control
- Data protection and secrets management
- Risk assessment and remediation tracking

## Responsible disclosure

If you discover a security issue, report it privately to the maintainers through your existing support/security channel. Do **not** open a public issue with exploit details.
