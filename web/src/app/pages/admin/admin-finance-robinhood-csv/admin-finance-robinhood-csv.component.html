Upload a Robinhood transaction export (.csv). The server saves it under the configured import directory (on Lightsail with docker-compose.robinhood.yml, the host folder is typically /home/ubuntu/robinhood/reports/import, mounted at /robinhood/import in the API container), then runs the same import pipeline as POST /import-csv. Leave Apply to database unchecked for a dry-run preview first. View imported rows under Finance → Trading → Transactions.
