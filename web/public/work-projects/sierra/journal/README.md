## How to add an entry

1. Copy [`_template.md`](_template.md) to `YYYY-MM-DD-short-slug.md`.
2. Add a row to the table below.
3. If the entry produces a durable fact, also update the matching module’s **Your notes** (and `../sources.md` if the source is new).
