# Agent Studio

No-code (and AI-assisted) IDE for the same agent engineers build in the SDK.

## Briefing

Agent Studio is how CX, operations, and engineering share one lifecycle: **build, test, deploy, optimize** without requiring every change to go through a software ticket.

**Agent Studio 2.0** (5 November 2025) is the “Shopify for agents” launch. Concrete pieces:

- **Journeys** — natural-language definition of goals and guardrails with enough nuance for production, not FAQ bots. Same building blocks as the SDK.
- **Workspaces** — “GitHub-style” collaboration across CX, ops, and engineering (safe branching / review, in their words).
- **Integrations in the UI** — pick from the library, add credentials and endpoints, publish; tools appear immediately for Studio and SDK. Claim: minutes instead of weeks of custom work.
- **Agent Traces** — real-time trace of every decision, tool call, and response while you author.
- **Simulations, Voice Sims, regression suites** — see [testing and release](../operations/testing-and-release.md).
- **Knowledge + Expert Answers + gap detection** — see [knowledge](knowledge.md).

Studio is also where you bind **tools and dynamic data** so replies stay current, and where you configure **custom integrations** on Sierra’s “opinionated integration framework.”

If Ghostwriter is the generator, Studio is the workshop where humans inspect traces, edit journeys, and hit publish.
